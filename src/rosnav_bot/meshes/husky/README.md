# Husky meshes

`visual/base_link.glb`, `top_chassis.glb`, `bumper.glb`, `top_plate.glb` are
a flattened, sensor-free export of Clearpath's `husky_description` chassis
meshes, used by `urdf/robot_core_husky.xacro`. Downloaded as static assets —
this repo has no git submodule or remote pointing at that project.
